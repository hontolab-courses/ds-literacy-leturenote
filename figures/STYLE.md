# 自作図解のスタイルガイド

policy/figures.md 3節の作成ルールを具体化したもの．全図で必ず従う．

## キャンバス

- SVG手書き（`<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 W H">`）．幅は900〜1100px，高さは内容に応じて
- 背景に白の `<rect>` を必ず敷く（ダークモード表示でも図が読めるように）
- 余白は四辺24px以上

## フォント

- `font-family="'Hiragino Sans','Noto Sans JP',sans-serif"`
- 本文ラベル16〜18px，強調・見出し20px（`font-weight="bold"`），注記13〜14px
- 日本語テキストは幅を取る．**1文字≒フォントサイズpx** で幅を見積もり，ボックスからはみ出さないこと

## 配色（カラーユニバーサルデザイン配慮，4色＋グレー）

| 役割 | 塗り（薄） | 線・文字（濃） |
|---|---|---|
| 主要素（青） | #EAF0F8 | #4C72B0 |
| 強調・対比・現在地（橙） | #FBEEE4 | #DD8452 |
| 肯定・OK（緑） | #EAF5EC | #55A868 |
| 否定・NG（赤，補助のみ） | #F9EAEA | #C44E52 |
| 注記・中立（グレー） | #F2F2F2 | #8C8C8C |

- 文字色は濃色（#333 または上記の濃色）．薄地の上に置く
- 赤と緑の対比**だけ**で意味を伝えない（×印・ラベルを併用）

## 図形

- 角丸長方形 `rx="8"`，線幅 `stroke-width="2"`
- 矢印は `<marker>` で定義した三角ヘッド＋線幅2の直線
- 点線（見かけの関係・弱い関係）は `stroke-dasharray="6 4"`

## ファイルと挿入

- ファイル名：`figures/chNN-<スラッグ>.svg`（共通部品は `common-<スラッグ>.svg`）
- 生成スクリプトがある場合は `figures/src/` に置く
- 本文挿入は `{figure}` ディレクティブ＋`:name: fig-<スラッグ>`＋`:alt:`＋キャプション．本文から `{numref}` で必ず参照する
- 図中の数値・比喩は本文に書かれているもののみ使う

## 検証（必須）

作成・修正のたびに以下でPNG化し，**画像を開いて目視確認**する（文字のはみ出し・重なり・誤字）．

```bash
rsvg-convert -w 1200 figures/chNN-xxx.svg -o /tmp/preview.png
```
